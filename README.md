# 🍔 FoodiePoint Hub - Canteen Management System

## 📌 Description

FoodiePoint Hub is a simple web-based canteen management system developed to automate daily canteen operations. It helps manage food items, stock availability, customer orders, and billing processes digitally.

The system provides two types of users:

- **Admin:** Manages menu items, stock, and customer orders.
- **Customer:** Views food items, places orders, and receives bill details.

The main goal of this project is to reduce manual work, improve canteen efficiency, and provide an easy-to-use digital platform for managing food services.

---

# 🚀 Main Features

## 👨‍💼 Admin Management

* Admin can manage all canteen menu items.
* Add new food products.
* Update existing food item details.
* Delete food items from the menu.
* Manage food stock availability.
* View and manage customer orders.
* Update and track order status.
* Maintain complete canteen item records.

---

## 👨‍🎓 Customer Ordering System

* Customers can view available food items.
* Search food items by name and category.
* Check available stock quantity.
* Place food orders easily through the system.
* Receive order confirmation details.
* View order history.
* Track current order status.

---

## 🧾 Order & Billing System

* Automatically calculates total order amount.
* Generates complete order details.
* Maintains order date and time records.
* Tracks order status:
  - Pending
  - Completed
  - Cancelled
* Stores customer order history.

---

## 🍔 Canteen Management

* Digital management of food items, prices, and stock.
* Reduces manual paperwork and human errors.
* Improves daily canteen operation efficiency.
* Provides a simple and user-friendly interface.
* Helps in maintaining organized food records.
